# Studio production display contract

Updated November 17, 2026. Applies to the existing shared phone/laptop app, not a new dashboard.

## Current deployed display
Home and Channels share the How It Ticks card. Status shows verified per-platform publishing and a dated snapshot. Buffer views display their separate source report time. Automatic jobs includes both repositories, with experiments distinguished from daily generation. Review lists and counts use paginated reads. Owner approval for How It Ticks remains manual.

## Full-video design requirements — pending implementation
Use an explicit format badge: Short (40–70 seconds), Original full video (2–5 minutes, native 16:9), or Legacy compilation. Do not label a compilation as the original full pipeline. A new original full video has one topic, one continuous explanation, original narration and landscape scenes, not portrait assets framed by blurred side panels.

In existing cards show title, actual duration, format, source-check time and honest quality state. Generated, inspected, delivered, approved, scheduled and platform-confirmed published are distinct states. A successful technical job is not scientific/aesthetic approval. Unknown or stale data must not become a reassuring zero or green pass. Keep the same app source, navigation and cache-update behavior on phone and laptop. Avoid duplicate screens.
